# ReceiptDesk outcomes

- [ ] Demo receipt data loads into an expense inbox with monthly total, tax total, category count, and category filters.
- [ ] Add receipt accepts pasted text or an attached image record and creates a structured expense row.
- [ ] Local/open-model support is attempted through an Ollama-compatible endpoint, with a deterministic offline parser fallback.
- [ ] Users can export the current expense rows as CSV.
- [ ] The interface clearly explains privacy, local processing, model swappability, and the paid freelancer use case.
