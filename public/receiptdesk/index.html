THE SHORT VERSION

A tiny finance tool
with boundaries.

ReceiptDesk is a concept for freelancers who want the convenience of AI without handing every receipt to a hosted API. It runs a predictable local parser by default and can hand the same extraction prompt to an Ollama-compatible open-weight model.

Try “Load demo receipts”, then export the rows. Everything in this demo lives in localStorage.
